## ADDED Requirements

### Requirement: 业务详情视图可通过 URL 恢复

移动端 SHALL 为客户订单/工单详情与配送任务详情提供可通过 URL 查询参数恢复的视图状态。该能力 MUST 在不依赖 SSR、Next.js 动态路由构建期参数或服务端 cookie 的前提下实现，与现有静态导出（`output: "export"`）方式兼容。

#### Scenario: 刷新页面后详情仍可恢复

- **WHEN** 用户打开某条订单或配送任务详情后刷新页面
- **THEN** 系统仍展示同一条记录的详情，而不是退回到列表视图

#### Scenario: 外部链接可直接打开详情

- **WHEN** 用户通过带有效详情标识的链接打开应用（如通知邮件中的"查看订单"链接）
- **THEN** 系统在完成登录态校验后直接展示对应详情，而不需要用户手动重新查找

#### Scenario: 无效或跨租户标识被拒绝

- **WHEN** 链接中携带的详情标识不存在、或不属于当前登录账号/租户
- **THEN** 系统展示未找到或无权限提示，不泄露该记录的任何信息
