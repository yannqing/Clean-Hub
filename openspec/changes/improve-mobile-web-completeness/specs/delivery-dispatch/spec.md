## ADDED Requirements

### Requirement: 派单看板门店与配送员列表查询

门店运营/Owner SHALL 能查询本租户的门店列表，以及按门店过滤的配送员列表，用于派单看板选择目标门店与配送员，替代手工输入门店/配送员标识的方式。查询 MUST 仅返回操作者所属租户范围内的数据。

#### Scenario: 查询本租户门店列表

- **WHEN** 门店运营打开派单看板的门店选择器
- **THEN** 系统返回本租户下的门店列表（至少含门店标识与名称），不包含其他租户的门店

#### Scenario: 按门店过滤配送员列表

- **WHEN** 门店运营选定某个门店后打开配送员选择器
- **THEN** 系统返回该门店下状态为启用的配送员列表（至少含标识与姓名），供派单/改派选择

#### Scenario: 跨租户查询被拒绝

- **WHEN** 操作者请求不属于自己租户的门店或配送员列表
- **THEN** 系统拒绝该请求或返回空结果，不泄露其他租户数据
