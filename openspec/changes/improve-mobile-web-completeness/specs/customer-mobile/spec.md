## ADDED Requirements

### Requirement: 查看首页运营概览

已登录客户 SHALL 能在首页 Tab 查看与订单列表内容不同的运营概览，至少包括：下一条待处理事项（最近的未处理预约或未完结订单/工单）、进行中与待取数量统计、发起新预约的快捷入口。首页概览的统计数字 MUST 与订单/工单列表使用一致的状态筛选口径。

#### Scenario: 首页与订单内容不同

- **WHEN** 已登录客户切换到首页 Tab
- **THEN** 系统展示概览卡片（下一条待处理事项、数量统计、常用入口），而不是订单/工单的完整列表

#### Scenario: 概览统计口径与订单列表一致

- **WHEN** 首页概览展示"进行中"数量
- **THEN** 该数字与订单 Tab 按"进行中"筛选得到的条目数一致

#### Scenario: 无待处理事项时的引导态

- **WHEN** 客户没有任何预约、进行中订单或工单
- **THEN** 首页展示引导发起预约的提示，而不是报错或空白页面
