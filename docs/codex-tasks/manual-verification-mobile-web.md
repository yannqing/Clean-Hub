# mobile-web 手动验证测试表

> 用途：验证 F1 三处 bug 修复 + OpenSpec `improve-mobile-web-completeness` 的 5 项手动验证任务 + 三角色回归。
> 填法：每条在「结果」列填 ✅通过 / ❌失败，失败时在「备注」写现象（越具体越好，最好附截图）。
> 反馈：把填完的表（或失败项）发我，我据此决定是否派 Codex 修 / 打勾 archive。

## 0. 前置环境

| 项 | 值 |
|---|---|
| 后端 API | 你稳定环境那套（:4100 或默认 :4000），确认 `curl /health` 返回 200 |
| mobile-web | dev server，端口需在 `.env` 的 `CORS_ORIGINS` 内（:3002） |
| 视口 | 手机尺寸（浏览器 DevTools 设 390×844，或真机/模拟器） |
| 门店代码 | `CLEAN-001` |
| 密码（三角色通用） | `123456` |
| 客户账号 | `zhang.wei@example.com`（登录选「客户密码」） |
| 配送员账号 | `mobile.driver1@cleanhub.local`（登录选「配送员」） |
| 店主账号 | `tenant.admin1@cleanhub.local`（登录选「店主」） |

> 说明：如某接口偶发 "Internal server error"，多半是 DB 连接抖动，刷新/重试即可；只有**稳定复现**才算 bug。
