# POS-T1101 集成与验收

## 当前实现范围

CleanHub POS Android 壳已通过设备厂商 AIDL 接入以下内置硬件：

- 内置热敏打印机：发现、测试打印、小票打印、多份打印、出纸。
- 内置扫码器：接收一维码和二维码扫描广播，并复用 POS 商品、工单和订单扫描流程。
- 钱箱接口：在现金收款或经理授权后调用设备钱箱接口。
- 硬件诊断：缺纸、仓盖打开、过热、忙碌、低电量、服务断连等状态。
- 断电恢复：打印前先写入现有本地持久队列；仅自动恢复“已要求打印但尚未开始”的任务。处于 `printing` 的任务不会自动重打，因为突然断电后无法确定纸张是否已经输出。

银行卡支付目前保持禁用。POS-T1101 资料只包含普通 NFC 和 Mifare 读卡能力，没有收单机构提供的 EMV、PIN、密钥注入和支付认证 SDK。不能用普通 NFC 接口代替银行卡收款。

## 设备和后台准备

1. 确认 POS-T1101 原厂系统中存在 `net.nyx.printerservice` 打印服务。CleanHub 不复制或替换设备系统服务。
2. 管理员在 Tenant 后台为目标门店和终端创建启用状态的打印机；如使用钱箱，再创建启用状态的钱箱。
3. 在 POS 的“设置 → 硬件设备”中检测 `POS-T1101 内置热敏打印机`，执行测试打印并保存绑定。
4. 扫码器使用设备内置扫描广播，不需要选择 USB 或蓝牙设备。后台仍可登记扫码器，作为门店资产和运维记录。

## Debug APK

电脑与 POS-T1101 连接同一个局域网，并确保 POS Web 可以从设备访问：

```bash
CLEANHUB_POS_SERVER_URL=http://<电脑局域网IP>:3001 \
CLEANHUB_POS_ALLOW_CLEARTEXT=true \
pnpm --filter @cleanhub/pos-mobile package:android:debug
```

打开设备的开发者选项和 USB 调试后安装：

```bash
adb devices
adb install -r release/pos-mobile/android/CleanHub-POS-0.1.0-1-debug.apk
```

生产包必须改用可访问的 HTTPS 地址，并使用正式签名，不能保留局域网 HTTP 地址。

## 实机验收清单

1. 首次启动后完成门店选择、终端登记和员工登录。
2. 设置页能发现内置打印机；正常、缺纸、开盖状态显示正确。
3. 测试页和真实订单小票能够打印中文、法语重音字符、`XOF`/`F CFA`、数量和金额。
4. 连续打印 1 至 5 份时份数正确，进纸位置适合当前纸宽。
5. 在销售页扫描已存在的条码只添加一次；未知条码显示未找到；扫码内容不能触发支付或授权操作。
6. 现金支付成功后，仅在后台已配置钱箱时开箱；相同支付不能重复自动开箱。
7. 在打印入队后、开始打印前强制结束应用，重启后任务自动恢复。
8. 在正在打印时断电，重启后任务显示“打印结果待确认”，不会擅自重复打印。
9. 关闭或杀死原厂打印服务后，CleanHub 显示硬件断连；服务恢复后能够重新检测。
