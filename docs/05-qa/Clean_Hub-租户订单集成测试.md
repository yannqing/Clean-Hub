# CleanHub 租户订单集成测试

租户订单集成测试覆盖订单详情页对应的高风险业务链路：

- 订单项目新增、编辑、删除与金额重算；
- 项目乐观锁版本冲突；
- 已付款订单禁止修改项目；
- 现金付款及付款幂等；
- 部分退款、退款幂等与超额退款保护；
- 付款金额减少/增加更正及更正幂等；
- 全额退款后的订单付款状态与操作能力；
- Timeline 数据源中的项目、付款、退款和更正审计事件。

## 运行条件

测试只要求本地 PostgreSQL 已启动并完成最新迁移，不依赖种子数据：

```bash
pnpm db:up
pnpm db:migrate
pnpm test:integration:tenant-orders
```

## 数据隔离

测试会在一个外层数据库事务中创建一次性租户、用户、门店、客户、服务、价格和订单。测试适配器会让业务服务复用该外层事务，避免提交任何中间数据。全部断言完成后，测试主动回滚外层事务，并再次查询租户和订单，确认没有测试数据残留。

如果任意断言或业务调用失败，数据库事务同样会自动回滚。

## 持续集成

`.github/workflows/ci-smoke.yml` 会在 PostgreSQL 完成迁移后自动运行该测试。任何订单金额、锁、幂等、退款边界或审计事件回归都会阻止 CI 继续构建。
